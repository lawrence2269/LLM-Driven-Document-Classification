This is a POC for a client with much bigger problem I have approximately 10-20 documents stored on a folder that currently lack a consistent classification. By using automated / AI‑based (**LLM**-based) document analysis, the documents can be classified according to the already existing classification policy.

Each document is automatically classified as:

	1. Green → moved to folder named *G*.
	2. Red → moved to folder named *R*.

In the filesystem, the goal is not to build fixed folder structures, but to use metadata and classification as the foundation. So, metadata extraction is needed along with classification. The solution reduces manual effort, strengthens information security, and provides a scalable, future‑proof approach to information management.
